# 🧠 Misión Neurodiversa: Descubriendo el Cerebro TDAH

Objeto de Aprendizaje Interactivo con gamificación para investigar, resolver retos y poner a prueba los conocimientos sobre el TDAH.

## 🗺️ Estructura del proyecto
- `index.html`: Ingreso de agente, elección de avatar y mapa interactivo de la misión.
- `aprender.html`: Base de datos con video explicativo, tarjetas interactivas (flip cards), pestañas de presentaciones del TDAH y datos curiosos.
- `reto1.html`: **Nivel 1 - Neurobiología** (circuito neuronal para completar, conectar parejas de funciones ejecutivas y casos prácticos).
- `reto2.html`: **Nivel 2 - Cazadores de Mitos** (juego de Verdad o Mito contrarreloj y chat anti-mitos).
- `reto3.html`: **Nivel 3 - Hackeando el TDAH** (clasificador de hábitos, memotest de estrategias y situaciones reales).
- `logros.html`: Salón de la Fama con calificaciones (1 a 10), estrellas, 10 insignias desbloqueables, bitácora de reflexión y certificado imprimible.
- `style.css`: Diseño visual, animaciones y estilos responsivos.
- `script.js`: Gestión de progreso en `localStorage`, XP, niveles, insignias, efectos de sonido y confeti.
- `juegos.js`: Motor de los 6 minijuegos y banco de preguntas/retos.

## 🚀 Cómo usar
Abrí `index.html` en cualquier navegador moderno o publicalo directamente con **GitHub Pages**.
